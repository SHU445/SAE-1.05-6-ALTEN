# Github commande : 

## Récuperer le repo 
    - git clone 'url'

## Actualiser le repo dans votre répertoire
    - git pull
    
### Récupère les informations du dépôt distant sans intégrer les modifications à la branche actuelle.
    - git fetch

## Push des modifications (3 étapes)
    - git add .

    - git commit -m "le commentaire du push ici"

    - git push origin

## Verfifier si il y à un commit à faire
    - git status

## Affiche les modifications effectuées dans les fichiers non indexés.
    - git diff

## Affiche les 5 derniers commit
    - git log --oneline -5
